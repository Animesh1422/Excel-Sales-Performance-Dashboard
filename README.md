# Sales Performance Dashboard | Microsoft Excel

## Project Overview

An interactive Sales Performance Dashboard developed using Microsoft Excel to analyze sales performance, profitability, product contribution, regional performance, and monthly trends.

The dashboard transforms raw sales data into meaningful business insights through visualizations and KPI metrics.

## Project Objectives

* Monitor overall sales and profit performance.
* Analyze monthly sales and profit trends.
* Identify top-performing products.
* Compare sales performance across regions.
* Understand category-wise sales contribution.
* Present key business insights in an interactive dashboard.

##  Tools & Techniques

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Interactive Slicers
* KPI Metrics
* Data Analysis
* Data Visualization

##  Dashboard Features

* Total Sales
* Average Order Value
* Total Profit
* Total Quantity
* Total Orders
* Monthly Sales & Profit Trend
* Category-Wise Sales Contribution
* Product-Wise Sales Analysis
* Product-Wise Profit Analysis
* Region-Wise Sales Analysis

##  Key Insights

* Total Sales: ₹7,12,500
* Total Profit: ₹1,62,400
* Total Quantity Sold: 108
* Total Orders: 25
* Highest Sales Contribution: Electronics
* Best-Selling Product by Revenue: Laptop
